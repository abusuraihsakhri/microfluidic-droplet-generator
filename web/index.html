Model assumptions

Spherical, monodisperse droplets; ideal random, independent Poisson loading; constant fluid properties. Predicted frequency uses the dispersed-phase volumetric flow only and assumes no loss.

These are estimates, not a droplet-size predictor, validated device simulator, clinical decision tool or GMP validation.
